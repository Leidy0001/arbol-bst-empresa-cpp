## Objetivo

Implementar un Árbol Binario de Búsqueda en C++ que permita organizar empleados de una empresa mediante códigos numéricos.

El sistema permite:

- Insertar empleados
- Buscar empleados
- Mostrar la raíz del árbol
- Recorridos:
  - Inorden
  - Preorden
  - Postorden
- Calcular la altura del árbol
- Mostrar nodos hoja
